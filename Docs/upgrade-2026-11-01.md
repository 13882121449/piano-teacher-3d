### Task 3B 真人静止手型（✅ 已完成，commit `9e25721`）

| 项 | 改造前 | 改造后 |
|---|---|---|
| 掌面朝向 | 侧立 / 朝天（腕部被绝对覆写，绕前臂轴滚转丢失） | 掌心朝下（`rest × delta` 合成 + 世界基向瞄准） |
| 五指 PIP 弯曲 | 18.2–35.6° | 18.2–35.6°（保持） |
| 指尖离键面 | +19.6 / +42.9 / +65.1 / +74.6 / +77.1 mm | **+10.5 / +1.8 / −6.1 / +13.1 / +42.5 mm** |

关键教训：**符号错误会让"看起来在弯"骗过指标**。`CharacterRocketboxTests.JointAxes_CurlMovesRealFingertipsTowardPalm`
（dot 应为负）抓出 `ImportedFingerJointAxes` 的轴被翻反——屈曲把指尖推向手背侧（dot=+45.9 mm）；
`HandIKController` 又直接把 `+up` 当作手背法线，而 `RocketboxHandRig.BackNormal` 实际朝掌心外侧，
于是"手掌朝天、越弯越高"（130–168 mm）。两处同时修正后指尖才真正落到键面。

### 阶段 1 追加（用户反馈三项：手型 / 纹理 / 踏板）

用户看 V17 后指出「左右手反了，手的纹理不符合物理常识，脚为什么没有动作」。三项的根因与修复：

| 反馈 | 根因 | 修复 |
|---|---|---|
| 左右手反了 | 腕部朝向只约束「手指前向 + 手背法向」，绕手指轴的扭转仍自由；右手 `canonicalX = thumb × SideSign` 的镜像基被 `LookRotation` 抹平，180° 滚转后左右手互换（画面上看到的是掌心与掌纹） | `HandIKController.ApplyWristOrientation` 改为「`FromToRotation` 对齐手指前向 + 绕该轴 `SignedAngle` 对齐拇指侧」，拇指侧取自新增的 `IHandOrientationRig.ThumbSideLocal` / `SideSign`；同时放开 `MaxWristRollDegrees` 钳制 |
| 纹理不符合物理常识 | ① 看到的其实是掌心；② `RocketboxTextureLibrary` 只 `SetTexture("_BumpMap")` 没开 `_NORMALMAP` 关键字，Standard/URP Lit 会整张忽略法线贴图 → 皮肤像塑料 | 补 `mat.EnableKeyword("_NORMALMAP")`（导入侧 `RocketboxTextureSetup` 早已按 NormalMap + BC5 处理） |
| 脚没有动作 | 数据侧 `MidiParser` 只处理 NoteOn/NoteOff，注释写明「CC 首版忽略」，无踏板字段；表现侧无任何脚部逐帧驱动，`Pedal_L/C/R` 只是静态黄铜摆件 | ① `MidiParser` 解析 CC64 → `SustainSpan` 半开区间；② 新增 `PedalFootAnimator`（世界空间水平俯仰轴、脚尖抬 13°、0.07 s 平滑）；③ `LessonSessionController` 接线；④ 无 CC64 的曲目用 `BuildAutoSustainSpans`（legato 自动延音，长音按 2.2 s 切段、0.03 s 换踏板） |

实测：内置三首 demo 的 CC64 事件数**均为 0**（必须走自动延音兜底）；`PedalSustainTests` 15 例、`PedalFootRocketboxTests` 8 例全绿，脚尖抬起约 28 mm、骨骼旋转 >5°、抬起后复位 <1°。

视觉证据：新增 `Docs/screenshots/V20_rocketbox_pedal.png`（V19 停止态 / V20 播放中命中踏板区间，同机位）。

已知局限：标准全景机位下右脚被琴凳与腿遮挡，踏板动作在截图上不易辨认，需要专门的脚部机位。
