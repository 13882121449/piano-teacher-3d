# 漫画星夜舞台交付记录

演奏全景使用靛紫天空、暖黄月轮和左右分层的漫画云。金边圆台为三角琴、琴凳和演奏者提供落地面，水面有滑动水光、扩散波纹和淡蓝琴体倒影。天空有缓慢流星与星光闪动。标准档保留完整构图，高画质档增强动效和泛光。人物使用已有角色模型，第一课继续用琴键特写和指法卡片。

## 成品

- Windows 使用版 `Builds/Windows/1114_漫画星夜舞台_v10/PianoTeacher3D.exe`。首页进入「演奏展示」或「继续上次演奏」，选择「全景」。
- `_verify_out/1114_漫画星夜舞台_v1/final/` 中的 `art.png` 是无界面全景，`stage.png` 是高画质界面实拍，`standard.png` 是标准档，`classroom.png` 是第一课，`motion.webp` 是 30 帧动效预览。

## 文件

- `Assets/Scripts/Piano/PianoSceneEnvironment.cs` 装配水面、琴台和灯光，管理可见性与画质联动。
- `Assets/Scripts/Piano/PianoKeyMap.cs` 调整琴身和琴盖使用的深蓝黑琴漆。
- `Assets/Resources/StarStage/` 的 `StarStageSky.shader`、`StarStageWater.shader` 和新增的 `StarStageInlay.shader` 绘制天空、水镜和台面镶嵌。
- `Assets/Tests/EditMode/SceneEnvironmentTests.cs` 验证舞台装配及档位，`Assets/Tests/PlayMode/VisualSnapshotTests.cs` 负责图形验收。
