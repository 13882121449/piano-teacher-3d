# 右拇指、女演奏者和钢琴返工验收

本次按先前的银蓝礼服人物三视图和最新的墨蓝钢琴三视图返工。与上版的同机位截图、三首曲目的逐帧数据和 Unity 日志位于 `_verify_out/1116_拇指与人物钢琴返工_v2/`。

## 右拇指

原解算每帧从很浅的弯曲姿势起算，允许中节和末节回到 0°，按下后又快速修正角度，快音中容易看见拇指拉直。新解算在连续动作中从上一帧的手型起算，为中节和末节保留轻微弯曲。按键附近限制角速度，跨键时根据指腹离目标的距离恢复追踪速度。预备、落下、保持和离键沿用同一组铰链，穿键时沿各关节标定的屈伸轴回退。

使用成年女演奏者、原速和 60 帧/秒记录。正确键帽指该帧的右拇指接触点处于目标键帽的测量范围。单帧角度变化取该帧三个关节中变化最大的一个。

- 《潮光》。保持期正确键帽为 371/371 → 371/371，落键期为 139/161 → 141/161。落键期最大单帧角度变化为 9.4° → 7.5°。
- 和弦。保持期正确键帽为 376/376 → 376/376，落键期为 55/55 → 55/55。最大单帧角度变化为 10.9° → 6.8°。
- 快速音阶。保持期末节转角低于 1° 的帧由 80/80 降到 0/80，保持期正确键帽均为 76/80。落键期正确键帽为 65/80 → 60/80。约 3.77 秒的高音区大跳仍有落键延迟。
- 旧版加跑定向回归时，右拇指末节屈曲和琴台纵深两项均复现失败。新版验证结果见文末。

## 女演奏者

重新制作头部体积、低发髻、碎发、肩颈、上臂和礼服。正、侧、背三面取样来自原人物图，投影到新头部网格。低背缎面裙、细肩带和银线刺绣分别成形，姿态在站姿和坐姿之间切换，角色卡使用 Unity 的实际渲染。手、前臂、鞋和演奏骨架沿用现有几何与校准。

五官采用三面照片投影。脸部极近景能看到贴图的分辨率限制，转到斜侧面时仍可见投影过渡。缎面褶皱、耳部、肩肘连接和坐姿裙摆仍是依照参考图建立的近似。

## 钢琴

新建有真实纵深的琴台、尖端上挑的主弧、横向副弧和纵向短拱。前侧采用贴地拉长的低音侧琴脚和向内回卷的高音侧琴脚，琴体后方增加独立落地支脚。琴弦连接主梁与琴台，端点有金色弦钮。琴台的工作高度仍取现有键面坐标，因此正面琴脚相对参考图偏高，雕饰也有所简化。

定向测试逐项比较 88 个琴键根节点、位置和旋转，以及随踏板转动的接触点。
