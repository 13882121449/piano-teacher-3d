# 1112 卡顿与贴键验证

本轮先测量首次合成钢琴音符的开销，再复测独立版。手掌调整单独做对照，避免把更深的穿键算成贴键改善。上一轮的改动与基线见[优化验证 v1](1112_优化验证_v1.md)。

## 首次发声

音频按音高缓存，第一次播放某个音符时才同步合成 2.5 秒波形。原来每个采样点、每个谐波都要计算正弦与指数。现在每个谐波先算出固定步进，然后在采样循环里递推相位与衰减；保留采样长度、谐波参数、击键噪声与归一化。

同机 PlayMode 专项测试，按 MIDI 音高列出单音首次合成耗时：

- 21：82.67 → 12.99 ms
- 48：62.55 → 7.93 ms
- 60：50.48 → 6.82 ms
- 84：35.70 → 4.74 ms
- 108：26.37 → 4.21 ms

旧实现 5 项均超出 20 ms，新实现 5 项均通过。五个音高各检查 11 个旧波形采样点（容差 0.0015）、峰值、声道、采样率与长度，共 5 项通过。该检查能发现波形数值回退，未执行人工试听。单音达标也不能保证多个未缓存音符同时发声时整帧达标。

证据：`_verify_out/history/1112_验证归档_v1/audio_red_v2.xml`、`_verify_out/history/1112_验证归档_v1/audio_green_palm_red_v2.xml`。后一个结果包含一个预期失败的手掌问题复现测试；音频 10 项全部通过。

## Windows 独立版

首次复测中，命令请求 1280×720，实际窗口却是 2560×1494。加入分辨率检查后，脚本能够拒绝该样本；仅靠 Unity 重新指定窗口仍有一次分辨率不符，最终使用无边框窗口，两场景均实测为 1280×720。正常启动不会创建采样器，也不调用测试窗口设置。前两组数据保存在 `_verify_out/history/1112_验证归档_v1/1112_audio_player_v2/` 和 `_verify_out/history/1112_验证归档_v1/1112_fixed_window_v2/`，分辨率不符的样本不用于下列对比。

在同一台独显开发机上，使用同一曲目和 High 画质，预热 2 秒、采样 20 秒。和 v1 的 1280×720 样本相比：

- 普通播放：p99 **18.10 → 16.93 ms**，1% low **24.93 → 47.81 FPS**，最慢帧 **113.68 → 49.55 ms**。
- 播放时切换视角与角色：p99 **17.00 → 16.92 ms**，1% low **24.62 → 50.90 FPS**，最慢帧 **135.99 → 31.87 ms**；实际切换 9 次。

两场景都通过 p99 ≤ 20 ms，仍未达到 1% low ≥ 55 FPS。窗口样式改为无边框，且每个场景仅取一次采样，不能把独立版所有改善都归因于音频。较可比的开播约 1.1 秒处，长帧从 113.68/135.99 ms 降至 22.55/31.87 ms；普通播放最慢的一帧现在出现在采样开始约 0.08 秒。切换场景约 6.02 和 14.03 秒仍有 22.04 和 26.68 ms 的长帧，接近切换边界，仅凭逐帧时间不能确定函数级原因。

原始逐帧数据与日志见 `_verify_out/history/1112_验证归档_v1/1112_borderless_player_v2/`。下一轮先对齐开播、首次音符合成与角色/视角切换的函数级耗时，再决定是否需要移动合成时机或处理切换渲染开销。

## 手部接触

诊断显示，旧逻辑会在指尖残差归零时逐渐撤掉已有的手掌偏移。尝试累加水平残差、到位后保留偏移，16 项手部专项测试通过。与上一轮基线对照如下：

- 黑键：悬空标记率 1.7% → 0.7%；穿键标记 175 → 352 帧。
- 和弦：悬空标记率 50.0% → 14.1%；穿键标记 216 → 340 帧。
- 快速音阶：悬空标记率 15.6% → 10.9%；穿键标记 193 → 235 帧。

该方案已撤回，保留此前的关节上限修复。实验数据取自 `_verify_out/history/1112_验证归档_v1/palm_ab_v2.xml`，上面的对照来自 `_verify_out/history/1112_验证归档_v1/play_final.xml`。撤回后的全量测试中，黑键、和弦、快速音阶的穿键计数分别为 203、342、197；和弦计数与试验接近，说明绝对帧数受时间步影响，不能断言试验让每首都变差。黑键在试验中仍比两次基线多出约 150 帧，且试验三首均未实现无穿键，因此暂不保留。现有悬空标记也受水平距离影响。后续应按分配手指记录水平误差、离键与穿键，再验证可达性约束，避免用有符号平均高度掩盖穿键。
