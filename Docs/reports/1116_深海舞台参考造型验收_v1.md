# 深海舞台参考造型验收

本轮按 [实施计划](../superpowers/plans/1116_深海舞台琴体女演奏者与拇指_v1.md) 处理鲸鱼、鱼群、右拇指、女演奏者、展示钢琴和深海配色。

## 舞台与造型

- 鲸首沿模型本地 X 轴，旧姿态固定抬首 32°。当前用路线切线定朝向，随游动节奏轻微点头和滚转，躯干波形向尾部加大，胸鳍独立轻划。曲目跳转和暂停后可复现对应位置。
- 两群鱼绕实际圆台中心沿不同高度、半径和方向游动，鱼头朝向切线。每条鱼有错开的尾摆和轻微升沉。
- 环境以偏绿的深海蓝做底，水面光斑和下照光束偏青蓝，远处的鲸体和阴影偏灰蓝。
- 演奏展示启用墨蓝金属薄型琴架。上扬主弧和内侧副弧之间排列竖弦，下方排列扇弦，两端有叠浪雕饰与卷脚。88 键及活动踏板使用原有坐标。
- 成年女演奏者沿用原脸部和演奏骨架，增加银蓝露背礼服、细肩带、坐姿裙摆、棕色低髻和发饰，并更新角色卡。近景仍保留部分原网格的领口轮廓，裙摆和发丝的细节与参考图存在差距。

## 测试

- Unity 2022.3.22f1c1 编译 0 错误。EditMode 509 项通过。默认 PlayMode 165 项通过、20 项跳过、0 项失败。另以图形模式运行固定机位录像和角色卡渲染，两项通过。
- 拇指预备阶段使用渐近的抬指弧线，松键时右拇指回到独立的轻弯姿势。三角色左右手各按一次白键与黑键，共 12 个触键工况。成年女角色右手白键和黑键的指腹水平偏差分别为 1.5 mm 和 1.7 mm，最近蒙皮顶点高于键面 0.4 mm 和 0.3 mm。此单音专项通过，快速音阶的整曲回归仍记录到悬空采样。
- 固定机位视频约 17 秒，1280×720，含钢琴音轨。第 14 秒截图能看到圆台、展示琴、女演奏者、灰蓝鲸体与两侧的鱼群。近景截图有演奏者侧后方和琴体背面。
- Python 验证工具自测 12 项通过。
