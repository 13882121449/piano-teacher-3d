# 真人触键与鲸影深海验收

Windows v13 可在「演奏展示 → 全景」查看新布景。舞台两侧有随水流摆动的海草，鱼群沿不同方向和速度成簇经过，大鲸缓慢游过中远景，暖色水母从冷色背景中显出轮廓。已在实际图形设备复看全景、钢琴近景、两个画质档及第一课。鲸、植物和鱼群由环境着色器绘制，近远层采用不同的相机视差。

## 真人视频与手部

本地《Amnesia》视频约 33 秒，键盘为俯拍。4.50–5.06 秒可见一部分手指换音时其余手指留在原位置附近。13.80–14.36 秒可见手部在相邻音之间小幅重分配，17.60–18.16 秒可见和弦保持时手掌轮廓相对稳定。镜头没有拍出足够的手腕侧面或脚部，无法从视频准确测量关节角和脚部动作。

现有动画只根据 MIDI 和角色骨架推算手型。按键时，旧代码在推进弹簧后又加一次追键，必要时再解除穿键。下一目标变化时，游离指也会快速折返。现在预备和离键用连续回落，继续保留已经按键时的快速追键和防穿键约束，追键计算合并到一次关节写入。改动位置为 `Assets/Scripts/Avatar/FingerPoseController.cs`。场景改动位于 `Assets/Resources/StarStage/StarStageSky.shader`。

- 女角色折返 10 → 3，正确键帽样本 322/336 → 322/336。

## v14 和弦触键复验

逐帧记录确认男角色和儿童角色都用右手拇指按 C4。和弦的腕位原先按未下沉的键面计算，但手指追踪的是正在下沉的键面。第一轮把所有音符的腕位目标都改为按到底的位置，男角色改善，女角色正确键帽从 322/336 降到 281/336。最终只对多个手指同时按键的腕位规划使用按到底的位置，并在共同腕位的评分中加重指尖悬空。参考位置由琴键动画的按键角度计算，实际手指依旧跟随当前键面。主要改动在 `HandIKController.cs`，`PianoKeyAnimator.cs` 和 `LessonSessionController.cs` 负责传入实际按键角度。

60 Hz 的 `near_hands` 专项中，三位角色均通过首个 C–E–G 和弦的 90% 门槛。用固定的 21 帧保持期窗口复算右手拇指 C4，并与 v13 的同帧对照：

- 女角色正确键帽 17/21 → 19/21，指尖离键高度中位数 5.22 → 4.02 毫米。整段正确键帽 322/336 → 323/336。
- 男角色正确键帽 0/21 → 19/21，指尖离键高度中位数 6.28 → 3.97 毫米。整段正确键帽 265/336 → 314/336。
- 儿童角色正确键帽 0/21 → 20/21，指尖离键高度中位数 7.91 → 2.86 毫米。整段正确键帽 249/336 → 276/336。
- 三位角色各采到 106 个有音符帧，超过 4 毫米的穿键均为零。关节角快速折返初始为 27 次，v13 为 14 次，v14 为 22 次。儿童角色由 v13 的 6 次升到 11 次，仍需改善换指过渡。
