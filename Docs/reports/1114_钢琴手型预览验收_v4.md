# 钢琴手型预览验收

本次产出包括可重复的 MIDI、测试、受限解算预览和原速与半速对照。短曲正确键帽率未过 95%，课堂默认仍使用 v6 演奏算法。v7 的 `-piano-hand-preview` 启动参数启用新指法、三角色受限解算和超跨度提示，供评审。

## 复现与诊断

用户截图没有曲名、时刻和指法数据。用含相邻双手和弦、黑键和弦、C 大调上行穿指的 `near_hands.mid` 重建相似问题。录像和数值是重建样本的表现。另有 `unplayable_span.mid` 故意让同一只手同时承担七音及超跨度。逐帧数据保存了分手、指号、按键状态、键帽本地落点、腕位、三关节相对绑定姿态与跨手指尖距离。

单指反例将目标移到指根侧后方，旧版指根脱离纯屈伸轨迹 41.6°，超过该案例 15.5° 的上限。新解算将侧摆限制在掌指关节，普通指最多 15°，拇指最多 25°。超过可达范围时保留有界姿势。挡住键面时沿屈伸轴回退。腕位按指根和键帽求平均落点，空闲手在靠近活动手时让位。目前仍没有完整的双手同时按键碰撞求解，也没重建用户截图的原帧。

指法在载入 MIDI 时预排。保持音的指号不因后续音插入而修改，重复音和进度跳转重新读取该音符事件的预排结果。超跨度复现中三个角色均未硬分配七音，并保留原曲时间轴。当前跨度以音程与指序筛选，三种角色用各自骨长求腕、指触键，还未做到按每种手掌独立重分手。

## 固定 60 Hz 对照

用相同的曲目时钟、镜头及键帽判据对比 v6 解算与预览解算。保持期正确键帽率包含所有活动音符，未触键音符另以音符数报告。延迟 P95 只涵盖曾触键的音符，须和触键音符数一起看。离键计任一活动指超过 6 mm，穿键计超过 4 mm。

- 女性原速，正确键帽从 280/336 降为 89/336，离键从 1/106 增为 41/106，触键音符从 20/20 降为 10/20，预览延迟 P95 为 3 帧。
- 男性原速，正确键帽从 212/336 降为 116/336，离键从 15/106 增为 65/106，触键音符从 17/20 降为 12/20，预览延迟 P95 为 5 帧。
- 儿童原速，正确键帽从 257/336 降为 172/336，离键从 1/106 增为 28/106，触键音符从 19/20 降为 14/20，预览延迟 P95 为 6 帧。
- 女性半速，正确键帽从 577/723 降为 159/723，离键从 3/218 增为 103/218，预览触键音符 11/20，延迟 P95 为 5 帧。
- 此次原速与半速对照，两套解算均没有测得超过 4 mm 的穿键。第一版受限解算曾出现大量穿键，调整腕位和增加限幅后才通过该项。

以第一组右手 C–E–G 为例，女性 G4 对应小指在触键起始 0.10 秒之后的落点中位数横向偏差，v6 为 17.8 mm，预览为 36.5 mm。此键的白键半宽为 12 mm。样本中即使指尖高度在键面附近，也会横向错键。后续需要联合调整腕部偏航、双手位置和指法候选，现有每手独立腕位加有限指根侧摆没有覆盖该动作。

对照画面可暂停和逐帧拖动，按正常帧时钟每三帧渲染一次。斜侧镜头在头部附近的裁切会露出模型内部，俯视画面用于对照双手相对位置。

## 验证

- Unity 一键验证退出码 0。编译 0 错误，EditMode 491 通过，PlayMode 151 通过、16 跳过、0 失败。
- 手型与角色专项 23 通过，超跨度专项通过。原速和半速两套解算共四次图形采样通过。全量无图形测试跳过了需 GPU 的课堂快照，专项做了手型对照。未执行全曲真人录像比对和长时间性能测试。
- Python 12 通过，架构、静态及差异空白检查通过。
- Windows 预览构建 0 错误、0 警告，启动出现主窗口并正常退出，退出码 0。冒烟只核对窗口启动和退出，课堂动作以编辑器专项和对照画面为依据。
