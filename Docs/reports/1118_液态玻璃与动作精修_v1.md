# 液态玻璃界面、琴键音画同步与手部精修验收（2026-11-18）

分支 `cf_develop_optimize`，基于 `bc7b361`。Unity 2022.3.22f1c1，RTX 4060 Laptop GPU。

## 界面：iOS 液态玻璃

- **背景模糊**：URP 渲染功能 `GlassBlurFeature` 在后处理之后，把画面缩到 1/4 分辨率，做 3 级双重 Kawase 模糊，写入全局纹理 `_PT3D_GlassBlurTex`。
- **玻璃着色器**：`FrostedGlass` 按屏幕坐标采样这张模糊纹理。
  - 玻璃体通透：只叠 22% 色调，再略向白色抬起。
  - 边缘带：沿法线向内折射，加镜面高光（左上亮、右下回光）和外沿一道亮线。
  - 边缘信息由玻璃九宫格贴图提供：R 通道存离边缘的接近度，G、B 通道存边缘法线。
- **面板与控件**：
  - 顶栏、底栏、浮层、卡片一律是面板玻璃；
  - 次级按钮、chip、分段的常态是更亮的控件玻璃；
  - 选中态是实心系统蓝 `#0071E3`，主按钮是白色实心。
  - 圆角为面板 28、按钮 20、chip 16，即胶囊形。
- **字体**：改为思源黑体 SC（Regular / Medium / Bold，SIL OFL 1.1，见 `Docs/licenses`）。粗体使用真实粗体字形。
- **主菜单**：背景由静态图改为实时 3D 海底舞台（`MenuStageBackdrop`），镜头缓慢环绕；「减少动效」开启时镜头静止。
- **修复**：
  - 提示框只在方向键导航时出现，打开「更多」后不再一直压在面板上；
  - 左上角提示卡加宽到 240，快捷键文字不再溢出。
- **截图口径**：`VisualSnapshotTests` 会让界面经过后处理，玻璃偏白。新增 `OverlayCaptureTests`（Explicit），按运行时的叠加方式截图。

## 音画同步

- **琴键运动**：琴键原来用指数逼近，60 fps 下约 100 ms 才压到 90%，而声音在 note-on 当帧就响。现在改为按键程计时：按下 16～32 ms（力度越大越快），松键回弹 70 ms。
- **起音时刻**：每个音统一在「音符时刻 + 25 ms」用 `PlayScheduled` 起音，帧相位带来的 0～16 ms 抖动被吸收。25 ms 约等于键程，所以声音在键到底时响起。
- **新增测试**：`AudioVisualSyncTests`（5 项）、`KeyTravelSyncTests`（2 项，真实帧循环下测键到底和回弹的用时）。

## 琴键与手部外观

- **琴键材质**：白键是暖白清漆键面，黑键是乌木清漆（URP Complex Lit Clear Coat）。材质资产由 `Editor/PianoMaterialAssets.cs` 生成到 `Resources/PianoMaterials`。
- **手部皮肤**：`ConcertLimbs` 着色器在底图是皮肤的地方（手、前臂）保留真实纹理并启用法线贴图，在衬衫布料处换成肤色；靠近肘部渐变回纯肤色。

## 指节穿模

- **新指标**：`KeyClearanceProbe` 把指根、各关节和节段中点当作带皮肤半径的球，在琴键局部空间里与键盒求距离。动作报告和 `[BENCH]` 日志里新增「指节穿键」的帧数和最深值。
- **诊断找到的两类问题**（`SegmentClearanceDiagnosticsTests`）：
  1. 演奏中没分配音符的休息手指垂进白键；
  2. 演奏手指从低腕斜压到相邻黑键的前角。
- **处理办法**：
  - 手在演奏时，休息手指在指根处按需抬起（最多 28°）；整手空闲时保持规格 C 形。
  - 整手抬腕会让指尖悬空（键面 P95 从 3 mm 升到 27.5 mm），所以默认关闭（`EnableSegmentClearance`）。
- **结果**：三首基准曲的最深值几乎没有变化（15.9 / 17.0 / 16.9 mm），这项指标仍然偏严。侧视截图里看不到明显的穿模，所以它只作诊断日志，不设门禁。
