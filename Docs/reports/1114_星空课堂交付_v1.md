# 星空课堂 v9 使用说明

启动 Windows 版后，选择「开始第一课」。先点「听示范」，看 3D 琴键和指号。右手从中央 C 开始，两小节每拍一音，顺序为 C–D–E–F｜G–E–D–C。

- 「等音练习」等你弹对再推进，弹错立即显示目标音和实际音。
- 「跟节拍」先响四拍，再按 60 BPM 练习。系统区分错音、漏音、早拍、晚拍和多弹，并能重练出问题的小节。
- 「独立弹奏」保留节拍，隐藏曲目音符、当前目标和指号，本轮结束后显示反馈。完成步骤会记录在本机。
- 可以点击屏幕上的五个琴键，也可以按 A、S、D、F、G。接 Windows USB MIDI 电钢琴后，在课堂右上角选「MIDI 设备」，再选择设备。首次插入设备后，重新打开设备列表即可刷新。
- 首页「演奏展示」进入星空舞台。全景可以看到云层、地平线与琴体倒影，「特写」可查看手部或琴键。

舞台由 Unity 实时渲染。星空、水纹和云层使用原创着色器，水中镜像使用共享三角钢琴网格。鼠标和电脑键盘可以验证教学流程，真实电钢琴主要用于练习键位和节奏。课堂根据音高和到达时间反馈，无法识别手指或手腕姿势。

## 验证

- Unity 编译 0 错误。全量 EditMode 501 项通过。全量 PlayMode 152 项通过、1 项失败、18 项跳过。失败项是快速音阶的跨手命中率，实测 90%，门槛 92%，单独复测结果相同。
- 最终构建前，单跑两项课堂交互测试和图形截图专项均通过。Python 12 项通过，架构、静态和差异空白检查通过。
