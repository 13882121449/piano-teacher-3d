# 流光舞台与三角琴交付

v11 的两层立体光带会沿不同方向绕行，光带内的亮线持续流动，远近云层分速漂移。琴台承重面与琴键、踏板接触位置维持原来的高度。全景镜头稍抬高并拉近，让琴体和弦框更容易看清。

琴盖使用 38 毫米厚的封闭网格和 9 毫米圆角。琴腿采用上粗下细的八边剖面，新增金属撑肋、琴壳窄边和轮座套环。琴漆按网格法线和视角算出冷暖反光，琴盖和琴壳会在不同角度呈现不同高光。人物沿用项目角色，未测试低配显卡的帧率。

## 成品与图像

- 本地 Windows 使用版 `Builds/Windows/1114_流光舞台与三角琴_v11/PianoTeacher3D.exe`。首页进入「演奏展示」后选择「全景」，也可切到「自由」从不同角度看琴漆。
- `_verify_out/1114_流光舞台与三角琴_v1/final/` 保存 `stage.png`、`standard.png`、`art.png`、`piano.png`、`classroom.png` 和 42 帧 `motion.webp`。

## 修改文件

- `Assets/Scripts/Piano/PianoSceneEnvironment.cs`、`StageRibbonMotion.cs` 装配背景光带、更新轨迹和画质强度。
- `Assets/Resources/StarStage/` 的 `StageRibbon.shader`、`StarStageSky.shader`、`StarStageWater.shader` 和 `StarStageInlay.shader` 绘制流光、漂移云层、水波和台面镶嵌。
- `Assets/Scripts/Piano/PianoMeshFactory.cs`、`PianoKeyMap.cs` 和 `Assets/Resources/StarStage/GrandLacquer.shader` 生成琴体细节与琴漆反光。
- `Assets/Scripts/Camera/CameraModeController.cs` 调整默认演奏全景。
- `Assets/Tests/PlayMode/GrandPianoGeometryTests.cs`、`VisualSnapshotTests.cs` 验证舞台运动、钢琴网格和实际 GPU 输出。

## 验证

- 旧版在新增的几何和光带检查中失败，实施后两项通过。D3D11 截图发现 HLSL 变量名冲突，修正后图形专项通过，拍摄了标准档、高画质档、钢琴近景和第一课。
- Python 12 项通过，架构与静态检查通过。
- Windows 构建成功，0 错误、2 警告，构建日志未输出警告详情。实测出现主窗口并正常退出，退出码为 0。
