# 深海水晶舞台与演奏比例交付

## 成品

- Windows 版位于 `Builds/Windows/1115_深海水晶舞台_v12/PianoTeacher3D.exe`。进入「演奏展示」，选择「全景」查看动态舞台。
- `_verify_out/1114_流光舞台与三角琴_v1/v12_final/` 保存 42 帧动图、三位角色全景、钢琴近景、标准画质和第一课画面。四宫格文件为 `roles_and_classroom.jpg`。

## 实施

- 从第一张参考图取深海蓝、斜射光与远景水母，从后两张取浅色琴身、冷色亮边和浅色座垫。水流、水纹、微粒和水母随时间变化。琴身使用不透明珍珠漆，靠浅蓝内衬与随视角变化的边缘反光表现水晶观感。
- 琴盖开合角度从 36° 收到 23°，撑杆随琴盖的几何计算落点。回归检查覆盖琴盖顶点低于 1.47 米、88 个琴键独立，以及键盘宽度 1.248 米。键床安装高度为 0.72 米。
- 琴凳改用实际落座的髋部坐标定位，座垫顶面作为坐姿基准。三位写实角色重复激活后，实测前后坐距参数 0.420 米、座垫离地 0.445 米、被测凳脚落地 0.000 米。三位角色共用这套琴凳设定。

## 改动位置

- `Assets/Resources/StarStage/` 的 `StarStageSky.shader`、`StarStageWater.shader`、`StarStageInlay.shader`、`GrandLacquer.shader` 修改海景、水纹、台面和琴漆。
- `Assets/Scripts/Piano/PianoSceneEnvironment.cs`、`PianoKeyMap.cs` 修改布景配色、琴盖和琴体材质。
- `Assets/Scripts/Characters/RocketboxCharacterView.cs` 修改琴凳生成及落座后定位。
- `Assets/Tests/PlayMode/SittingPoseTests.cs`、`GrandPianoGeometryTests.cs`、`VisualSnapshotTests.cs` 验证人物比例、网格和场景渲染。

- Python 12 项通过，Git 差异空白检查通过。
- Windows 构建 0 错误、2 警告。构建汇总未列出两个警告的详细内容。主窗口出现后正常关闭，退出码 0。

- 静态检查和架构规则通过。三首基准曲的键面距离 P50 均为 3 毫米，穿键计数均为 0。黑键、和弦、快速音阶的悬空率分别为 1.2%、4.0%、7.1%，后两项仍高于项目的 2% 目标。
