## 如何新增 / 更新基线

1. 在有 GPU 的机器上生成截图：跑 `python Tools/verify.py --visual`（该阶段**不加** `-nographics`，需要真实 GPU 渲染），
   或直跑 `Unity.exe -batchmode -runTests -testPlatform PlayMode -testFilter CaptureLessonViews`（**不要**加 `-nographics`）。
2. **人工看图**确认构图、遮挡、穿模与颜色语义无误（方案 11.2 末段 / 审查 6.1）—— 这一步不可省略。
3. 把确认无误的图复制到 `Docs/screenshots/baseline/`（同名覆盖），再提交 `baseline/` 与本文件。
4. 之后可用 `python Tools/verify.py --compare-visual`（等价于只跑本用例的重型比较）或直接跑
   `python Tools/visual_diff.py Docs/screenshots/baseline Docs/screenshots` 做自动像素对比辅助。
