# 资产许可证清单（asset-licenses.md）

> 对应方案 6.5「资源评估原则」与 2.1 设计原则「遵守资源许可证」。
> 本清单随第三方资源每次更新同步维护。

## 1. 当前项目资产（首版，全部程序化生成，零外部资产）

| 资产类型 | 来源 | 许可证 | 说明 |
|---|---|---|---|
| 钢琴模型（88 键） | `PianoKeyMap` 程序化 `Cube` | 自研（无第三方） | 无需授权 |
| 3D 人物（3 角色） | `AvatarManager` 程序化球体/胶囊/盒体 | 自研（无第三方） | 无需授权 |
| 材质 | `Shader.Find("Standard")` + 纯色 | Unity 内置 | 随 Unity 许可 |
| 音频 | `PianoAudioSynth` 波形合成 | 自研（无第三方采样） | 无需授权 |
| 演示曲目 | `StreamingAssets/Songs/demo.mid` | 程序生成（C 大调音阶+和弦，原创） | 无需授权 |

> 结论：首版**不包含任何第三方代码/模型/贴图/动作数据/音频采样**，无许可证风险。
> 后续引入任何外部资源前，必须补登记到第 3 节表格并经许可核对。

**重要提醒（方案 6.5）**：代码许可证（MIT/Apache-2.0）**不等于**其第三方依赖、模型、贴图、动作数据、
音频样本、模型权重均可自由商用。集成前必须逐项核对：
- 仓库地址、固定 commit/release 版本；
- 代码许可证与版权声明；
- 3D 模型/贴图/动作数据/权重/音频文件的**独立许可证**；
- 是否允许商业使用、修改、再分发，是否要求署名或附带许可证；
- Unity 版本兼容性、性能、依赖与安全风险；
- 能否稳定映射到本项目琴键位与人物骨骼规范。
