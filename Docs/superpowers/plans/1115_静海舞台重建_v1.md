# 静海舞台重建计划

- [x] 核对参考图和旧版实拍。旧版用方向球绘制鲸、鱼和海草，用平面承担水纹。检查 Unity 2022.3 和 URP 14 的装配、质量档及教学切换入口。
- [x] 查阅 [URP Water Shaders](https://github.com/aniruddhahar/URP-WaterShaders)、[Keijiro Boids](https://github.com/keijiro/Boids) 和 [Quaternius 鱼类模型](https://quaternius.com/packs/animatedfish.html)。采用世界坐标焦散、错开的鱼群流向及可摆尾的三维轮廓。按参考图自行做海洋网格和琴体，保证比例、配色和材质统一。
- [x] 重建海床和生物。`UnderwaterStage` 装配近景礁石、珊瑚、长叶海草、中景鱼群和慢游的座头鲸。用实际几何遮挡、分层水雾和水面亮度把主体和远景分开。批量合并小物件，共用材质。
- [x] 增加斜照舞台中央的阳光和缓慢变化的焦散。追加 `UnderwaterScenery` 和 `UnderwaterSun` 着色器，控制散射强度并借助场景深度保护角色、琴键和近景。保留标准档和高档可用。
- [x] 在 `PianoKeyMap` 装配参考图款式。演奏展示使用深蓝漆面、斜升弧梁、竖弦和曲形琴腿。教学模式使用现有琴体外观。保留 88 个琴键、踏板接触点和骨骼依赖的坐标。
- [x] 实拍标准档、高画质、侧向观察和第一课，检查海洋对象是否随换机位呈现视差，琴键是否保持清楚。运行 Unity 回归和 Windows 打包，验证启动、退出并记录测试与素材参考。见 [验收记录](../../reports/1115_静海三维舞台验收_v1.md)。
