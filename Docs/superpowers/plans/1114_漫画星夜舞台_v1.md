# 漫画星夜舞台优化计划

**目标**　把演奏全景改成一眼可辨的动画夜景，让钢琴落在真实可见的琴台上。第一课仍需清楚显示琴键和指法。

**取舍**　Unity Toon Shader 提供分层光色参考，Roystan 的水面教程提供波纹、水色和高光的参考。全屏漫画后处理会同时改变角色和键面，固定背景图则会限制自由观察。本版在现有 Unity 2022.3 / URP 中，用项目自己的程序化天空、水镜和琴台表现漫画场景。

- [Unity Toon Shader（GitHub）](https://github.com/Unity-Technologies/com.unity.toonshader)
- [Roystan《Toon Water Shader》](https://roystan.net/articles/toon-water/)
