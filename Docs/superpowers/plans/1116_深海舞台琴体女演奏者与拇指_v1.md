# 深海演奏舞台与右拇指修复计划

目标是让固定镜头下的鲸鱼和鱼群按自然路径游动，按三视图重做展示琴壳及成年女演奏者造型，并检验右拇指从预备到落键、释放的连续性。

- [x] 在 `StageDirectionTests.cs` 增加鲸首仰角、鱼群绕舞台闭环和鱼首朝切线的回归检查。检查 `UnderwaterStage.cs` 的鲸首为本地 +X，去掉固定 32° 仰角。让鲸首跟随低坡度游向，躯干、尾鳍、胸鳍用同一拍动周期及相位差。鱼群使用以圆台为圆心的不同高度和半径，单鱼保留摆尾和轻微错相起伏。
- [x] 修改 `UnderwaterScenery.shader`、`UnderwaterSun.shader` 和 `StarStageSky.shader`。以偏绿的深海蓝为环境底色，用青蓝色强化光束与焦散，远距渐变保留偏灰蓝的鲸影和阴影。用固定机位检查轮廓和手部可见性。
- [x] 在 `GrandPianoGeometryTests.cs` 检查琴架深度、弧梁高度和琴键、踏板坐标。重做 `CinematicPianoCase.cs` 的薄型展示琴壳，采用墨蓝金属、上扬主弧、下部副弧、直弦与扇弦、卷浪雕饰和卷脚。
- [x] 在成年女角色创建路径接入新造型。以银蓝吊带露背礼服、收腰长裙、编发低髻和发饰为验收特征。沿用角色的手部骨骼和脸部资产，在原骨架上制作三维服装及发型，检查坐姿、肩肘和踏板空间，复核其他角色切换。
- [x] 在 `FingerPoseController.cs` 和 `HandIKController.cs` 追踪右拇指的持续预备、落键和回弹。根据现有约束加入平滑的过渡和自然预备屈曲，按白键、黑键、和弦与快速换指检查接触和邻键。
- [x] 运行 Unity 定向测试和 `python Tools/verify.py` 等价全量检查，将新日志写入独立目录。使用有图形设备的固定机位采样核对海底动态、人物衣装和琴壳，再生成独立 Windows 成品并试跑。汇报实测结果和遗留项。
