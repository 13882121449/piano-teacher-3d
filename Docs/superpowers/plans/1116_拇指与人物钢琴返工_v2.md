# 右拇指、女演奏者和钢琴返工计划

女演奏者以此前提供的银蓝礼服三视图为准，钢琴以本次提供的新三视图为准。三个问题分别在整曲近景、人物三视图和琴体三视图验收，最后在同一个 Unity 演奏场景中联调。

## 1. 右拇指

- [x] 用现有版本录《潮光》、和弦及快速音阶的同机位右手近景。用 `HandBenchmarkTests.cs` 的逐帧采集同步记录腕位、拇指三节转角、按键时刻和指腹到键面的距离。先标记预备、落键、按住、松键和跨指换位各阶段的异常帧。
- [x] 核对 `FingerPoseController.cs` 每帧关节求解初值、接触追踪的角速度以及键面回退，再核对 `HandIKController.cs` 键位目标和腕位变化。用帧轨迹确认僵硬来自哪一段后再修改对应层。连续动作检查同时覆盖指腹与邻键。
- [x] 同速度、同视角、同曲段录制前后对比。报告异常发生的时间、动作阶段和修复后剩余帧。单音贴键只作为回归检查。

## 2. 女演奏者

- [x] 建立新头脸、头发和服装网格。以原女角色参考图还原五官比例、自然发际线、两侧碎发、带小饰物的编发低髻、露肩露背轮廓及银蓝缎面长裙。制作完整的领口、肩带和布褶。
- [x] 将新网格与可演奏的身体、手、脚骨架绑定。先在中性光下对照正面、侧面和背面，再检查坐姿时肩肘、裙摆和踏板区域。用实际渲染更新角色卡。
- [x] 当前项目没有符合参考的女模资产。实施时先确认可用的本地建模、蒙皮和导入链路，再选择建模方案。使用付费素材或外部上传服务前另行确认。

## 3. 展示钢琴

- [x] 按新图描出正面、侧面、背面轮廓，以键盘宽度对齐视图，以舞台地面校准支脚。重新建横向延展的非对称底座，一端贴地拉长，另一端内卷。侧视图包含琴台纵深、支脚落地和侧后方内拱。
- [x] 新琴架做尖端上挑的主弧、横跨键盘的副弧、短内拱、逐根弦与弦钮。用沿曲面连续的青蓝镶边表达墨蓝金属高光。
- [x] 在 `CinematicPianoCase.cs` 和外形资产中替换展示琴壳，同 `PianoKeyMap.cs` 的 88 键、踏板与触键坐标对齐。验收以键盘侧、侧面和背面同视角渲染为准，另检查键程和演奏者膝部空间。

## 4. 联调与交付

- [x] 运行 Unity 编译、EditMode、PlayMode 和定向图形验收。交付右手同机位对比、人物和钢琴三视图、新版 25 秒以上的 Windows 演奏烟测日志及单独目录中的可执行成品。把仍可观察到的造型或动作偏差写入验收报告。

逐帧数据、造型偏差和打包结果见 [返工验收](../../reports/1116_拇指与人物钢琴返工验收_v2.md)。
