# 流光舞台与三角琴优化计划

**目标**　从默认全景就能看出布景在移动，转动视角时能看见三角琴的厚度、轮廓和随视角变化的漆面反光。键面和踏板仍可用于教学。

## 1. 动态舞台

- [x] 先在 PlayMode 中确认两层空间光带会独立移动，并跟随环境开关。
- [x] 在 `PianoSceneEnvironment.cs` 装配舞台光带，在 `StageRibbonMotion.cs` 和 `StageRibbon.shader` 实现真实空间里的缓慢绕行、彩色边缘和流光。分层更新 `StarStageSky.shader` 的云和背景光晕。
- [x] 保留钢琴与琴凳的接地高度，压低圆台装饰和水波亮度。调整 `CameraModeController.cs` 的默认全景以增加琴弦和琴盖内侧的可见面积。

## 2. 三角琴细节

- [x] 增加网格断言，确认琴盖存在实体圆角，琴腿上粗下细，弦上方有铸框支撑。沿用 88 键和踏板接触测试。
- [x] 在 `PianoMeshFactory.cs` 生成带圆角的琴盖与渐细琴腿，在 `PianoKeyMap.cs` 装配金属琴肋、边缘及轮座。在 `GrandLacquer.shader` 为深色琴漆加入随视角移动的冷暖软反光。

## 3. 验收与构建

- [x] 运行新增 PlayMode 检查，使用真实图形设备拍两个画质档的全景、钢琴近景、第一课，以及能看见光带运动的 42 帧预览。
- [x] 查看实拍后修正遮挡、曝光或严重锯齿。运行 `python Tools/verify.py`，并构建和启动 Windows 版。
- [x] 截图、动图和测试日志存入 `_verify_out/1114_流光舞台与三角琴_v1/`，使用版存入 `Builds/Windows/1114_流光舞台与三角琴_v11/`。

## 4. 按实拍参考改成深海舞台

- [x] 第一张用于确定演奏全景的深蓝背景、斜射光和远近层次。后两张用于确定珍珠白琴身、冰蓝透光边和金属细节。以这两种风格组成一个舞台。
