# 海底舞台动态与拇指接触修复计划

**目标**　固定镜头也能看到海底生物和水流在动。左右拇指按到指定琴键，并减少指腹或指节穿键。

1. **复现。** 在 `Assets/Tests/PlayMode/StageDirectionTests.cs` 检查生物三个深度层的变形数据和同机位持续位移。在 `Assets/Tests/PlayMode/HandFingerCorrespondenceTests.cs` 对写实男女角色分别测试左右拇指的白键和黑键，输出横向与高度误差。
2. **修复海底舞台。** 在 `UnderwaterStage.cs`、`StageMesh.cs` 与 `UnderwaterScenery.shader` 为海草茎叶、水母触须和悬浮颗粒加水流形变。让鱼群转向随游速变化，鲸鱼的换段位置保留曲目同步。验收时关闭自动运镜，从固定机位比较连续帧，复查教学模式和演出暂停。
3. **修复拇指触键。** 检查 `RocketboxHandRig.cs` 的指腹位置，`FingerPoseController.cs` 的拇指掌侧对掌方向和屈伸自由度，以及 `HandIKController.cs` 的腕位与实时键面目标。按回归误差决定最小改动，沿用指法和骨长，从出发、触键、按住到松开验证。
4. **验证和交付。** 执行 Unity 编译、EditMode、PlayMode 和曲目基准。用 Windows 构建与画面证据核验，记录实际测到的偏差和已知边界。
