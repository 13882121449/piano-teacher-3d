# 星空舞台与第一课计划

**目标**　让初学者完成两小节练习并收到可操作的反馈，把演奏展示做成深蓝星空与水镜舞台。

1. [x] 新增第一课状态逻辑与测试。固定 C4 到 G4 的右手指法，示范后逐音等待正确键、按拍练习、关闭音符提示独立弹。区分错音、漏音、早拍、晚拍，记录错处所在小节并能重练。
2. [x] 在首页加第一课和继续练习入口、保留演奏展示。课堂接收屏幕键盘、电脑键盘与 Windows USB MIDI 设备输入，练习提示遵循当前模式，保存可恢复的进度。
3. [x] 把演奏环境改成原创星空水镜。用远景星空、云层轮廓、冷色天空、地平线与低亮反射还原参考图的气氛。背景与琴罩、手部特写保持对比度。截图只作为构图与色彩参考。
4. [x] 运行 Unity 编译、EditMode、PlayMode、课堂与星空图形专项。构建 Windows 版并冒烟，交付报告记录真实设备和学生评估的验证状态。


验收结果见 [交付记录](../../reports/1114_星空课堂交付_v1.md)。全量 PlayMode 的快速音阶跨手命中率基准仍未过线，已复测并记录。
