交付可运行的 Windows 体验版。覆盖女、男、卡通三个角色的实际卡片切换、教学模式下的高亮切换，以及继续练习打开的课堂。

## 2. 修复角色与高亮状态

- [x] 调整 `AvatarSelectionUI.cs` 和 `LessonSessionController.cs`，通过会话切换角色，在视图变更时统一刷新解算器、手指骨架和关节轴。
- [x] 在 `UserPreferences.cs` 保存教学高亮设置。旧设置文件的教学模式默认沿用「发声」。切换高亮保留正在按下的音符，以便重新打开时立即恢复着色。

## 3. 平滑手腕和手指

- [x] 在 `HandIKController.cs` 换人时清除依赖原骨架的速度、修正和腕部朝向状态，保留播放的音符与预备信息。
- [x] 延续前一帧腕部世界角度来平滑新目标，避免前臂解算每帧改变插值起点。降低正播放的和弦在起音后再次抬指的幅度。
- [x] 在 `FingerPoseController.cs` 让指节保持连续角速度。检查换人、快速音阶、持续和弦和释放，记录三个角色的行为。
- [x] 三角色第一轮量测后，在 `AvatarDefinition.cs` 和 `RocketboxCharacterView.cs` 为男角色单独标定演奏腕高。用相同曲目复测。
- [x] 真人依据包括钢琴连奏提前调整、专家八度动作中的肩肘腕协同，以及同步俯拍参考。以运动特征指导程序动画。
  - [前瞻动作研究](https://pubmed.ncbi.nlm.nih.gov/9063705/)
  - [专家触键动作研究](https://pubmed.ncbi.nlm.nih.gov/17989970/)
  - [PianoVAM 实拍数据说明](https://arxiv.org/abs/2509.08800)
  - [SKY-Piano 真人多视角动作捕捉参考](https://joonhyungbae.github.io/skypiano/)
