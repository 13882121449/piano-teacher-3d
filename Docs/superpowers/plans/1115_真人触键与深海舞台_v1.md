# 真人触键与深海舞台计划

- [x] 逐帧看《Amnesia》钢琴视频。约 2–6 秒可见手指轮换时指尖留在键面附近，约 12–20 秒可见和弦转换时掌位整体移动。俯拍用来看落键与换位，关节角度和踏板动作无法从这个角度确认。
- [x] 用近手样本量化相邻帧的关节反向摆动，区分主动换指和保持期抖动。用三首长基准曲检查原有触键指标。检查防穿键反馈和几何门槛对指关节的影响。
- [x] 在现有手指解算中，让持续触键与待机平滑各有明确的过渡，压低关节反向摆动。对照三角色相同片段，保留穿键与落点检查。
- [x] 沿参照的构图，在舞台两侧布置摆动海草，中远景加入跨越不同深度的鱼群、暖色水母和斜游鲸影，调整光束、背景层次及台面反射。第一课保持键面清楚。
- [x] 图形设备实拍全景、近景和第一课，输出动图。运行 Unity 回归、打包 Windows，并验证启动退出。分别报告触键动作测试指标与视觉观察。
- [x] 复查右手 C–E–G 和弦，修正腕位规划的下沉键面参考。三角色专项通过。对照三首完整基准曲，打包 v14 与手部预览启动器。默认模式跨手门槛、预览模式快速音阶的悬空目标和儿童换指折返仍有差距，见验收报告。
- [x] 继续对照儿童角色短片段和完整快速音阶的逐帧数据，区分起奏手部从远处移动、和弦内重复修正，以及曲中大跳三种情况。
- [x] 开播和重播统一准备腕位和指尖。保留已贴到键面的和弦手型，超出接触范围后继续追踪。增加从高音区重播首个音符的回归测试。
- [x] 复对照触键和穿键、运行默认模式全量回归及预览模式专项，在本地验证 v16 两个启动入口。快速音阶悬空 3.9%，曲中大跳仍需优化，详见 `Docs/reports/1115_开播摆位与儿童手型验收_v1.md`。
