# 1116 人物重建、手部动作与舞台琴返工 v3

- [ ] 从 GitHub 核对人物重建源码、权重、许可、显存要求。用本地图片做推理，检查正面、侧面、背面。达不到使用要求的输出不接入正式场景。
- [ ] 排查钢琴演奏中的右拇指动作链。用快速音阶、和弦和《潮光》分开查首帧、按住、换位、回弹与其他四指。用可重复轨迹比较修改前后，不放宽验收阈值。
- [ ] 原创“深潮”演奏琴：低矮弧面琴壳、深蓝黑漆、青蓝细边，保留视觉留白。演奏侧能看到手与 88 键，保留踏板和交互，灯光下看剪影。
- [ ] Unity 统一编译与验收，输出实际渲染和 Windows 构建（构建检查通过后）。记录模型是否接入、轨迹数字与未通过的地方。
