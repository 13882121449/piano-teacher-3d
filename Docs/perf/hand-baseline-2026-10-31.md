## 3. 结论：两项默认关闭

### 3.1 腕高自适应（条目 2.4）→ `WristHeightAdaptation = false`

| 观察 | 数据 |
|---|---|
| 均值口径（v1）几乎无作用 | 键面 P95 三曲变化 +1.9 / +0.2 / −0.5 mm；压键帧 −3 / −3 / 0 |
| 主因：均值把极端值平均掉了 | 一手 5 指若 3 指悬空 20 mm + 2 指压入 8 mm，均值只有 +8.8 mm，落在死区（−6 ~ +15 mm）内，永不修正 |
| 改为极值+中位数（v2）仍无有效收益 | 压键帧与 v1 差 −1/+5/+5（噪声内）；悬空帧 −7/+0/+0 |
| 作用量级不匹配 | 限幅 ±8 mm，而真问题是键面 P95 17–46 mm、压键数百帧 |

**根因判断**：键面距离与压键的主因是**手指弯曲不足**（指尖到不了目标），属于手指姿态链路
（批次 4 的 C 形手 / 三关节弯曲分布），不是腕高偏置。腕高反馈只能治「整手系统性偏高/偏低」，
而当前问题在**同一只手内部的指间差异**，任何单一腕高偏移都会同时让一部分指更差。

**处理**：实现与参数（`MaxWristHeightAdaptation` / `WristAdaptationSmoothSeconds` /
两个阈值）全部保留，默认关闭；待批次 4 改善弯曲后复测，若届时仍需腕高补偿再开启并重新标定。

### 3.2 黑键目标抬升 → `BlackKeyTargetLift = 0`

| 观察 | 数据（`bench_black_keys`） |
|---|---|
| 抬 3 mm 确实生效 | 键面 P50 9.1 → 11.0 mm（+1.9，指尖整体上移） |
| 但几乎不减少压键 | 压键帧 110 → 107（−3，噪声内） |
| 键面距离全线变差 | P50 +1.9 mm、P95 +1.9 mm |

**根因判断**：该曲压键帧的平均压入量远大于 3 mm（3 mm 抬升只能救临界帧），
所以「抬目标」无法解决，必须靠弯曲控制让指尖能停在目标高度。

**处理**：保留参数（默认 0），批次 4 弯曲改善后配合调参复核。

## 4. 当前生效基线（供门禁断言使用）

默认值关闭后，实际行为与 `cdd56d9` 一致，故当前生效基线 = 上表 A 列：

| 曲目 | 键面 P50 | 键面 P95 | 悬空帧 | 指尖压键帧 | 命中率 |
|---|---:|---:|---:|---:|---:|
| `bench_black_keys` | 9.1 | 10.2 | 3 | 110 | 99.9% |
| `bench_chords` | 5.0 | 11.2 | 332 | 301 | 99.1% |
| `bench_fast_scale` | 3.6 | 17.7 | 54 | 17 | 95.5% |

**与批次 3 目标门禁的差距（诚实记录，未达标）**：

| 目标 | 要求 | 当前 | 差距 |
|---|---|---|---|
| 键面 P95 | ≤ 15 mm | 10.2 / 11.2 / **17.7** | `fast_scale` 超 2.7 mm |
| 悬空帧 | ≤ 3 | 3 / **332** / **54** | 和弦与快速音阶大幅超标 |
| 指尖压键帧 | = 0 | **110** / **301** / **17** | 三曲均未达标 |

这三项的门禁**不写入断言**（写入会立刻红），原因与归属：悬空/压键的主因在弯曲链路，
属批次 4 范围；大跨度换位峰值（250.7 mm）属 2.3 可达性范围。门禁断言化推迟到批次 4
完成后一次性收紧，届时以本表为对照。
